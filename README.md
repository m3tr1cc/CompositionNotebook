# CompositionNotebook

An interactive Codefair-ready composition notebook cover. The app fills the available project frame with a black-and-white notebook pattern, a ruled label, smooth handwriting inside the label, pen controls, clear, and image download.

## Stack

- Vite
- React
- TypeScript
- Canvas 2D
- Plain CSS
- Vercel static deployment

## Scripts

```bash
npm run dev
npm run lint
npm run check
npm run build
```
